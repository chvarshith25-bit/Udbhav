# Homepage design context

The user-selected direction is **The Festival Is Yours**: a single-screen interactive college festival entrance, continuing the approved Campus Takeover intro.

- Stack: existing React 19, Vite, GSAP, React Router and CSS. No new runtime libraries.
- Tokens: ink #171914, paper #f3f2eb, lime #d7f34d; restrained clay #dbad91 and blue #b8c7ec lighting. System Arial/Helvetica typography.
- Composition: oversized UDHBHAV identity, one original illustrated ground, spatial court/stage/pavilion entrances, secondary venue-style Sponsors button.
- Interaction: one active lighting zone, finite event-triggered motion, existing TransitionLink navigation, keyboard focus equivalence and first-tap touch navigation.
- Mobile: simplified signs with distinct vector symbols and real event names; the panorama is atmospheric rather than essential navigation, and is omitted on very short screens.
- Sponsors: native accessible modal; centralized empty data; no invented organizations, logos or sponsor tiers.
- Protected: intro source/timing/session rules; shared header/VJIT branding; category pages, details, registration and route transitions.
- Source references: src/home/, src/sections/Hero.jsx, src/pages/HomePage.jsx, src/data/sponsors.js, DESIGN_SYSTEM.md.

The installed 21st.dev local context/review tools were used. Hosted search/generation is not connected; no external templates or component code were retrieved. The JSON context records the user brief and scoped decisions.

## Cultural design context

The current brief supersedes the broadcast concept with **The Festival Street**. One illustrated world connects Performance Boulevard, Creator’s Alley and Challenge District. Angled wayfinding signs, responsive architecture, perspective paving, festive light and original interactive event posters communicate a lively college celebration. District changes recompose the same environment in 0.85 seconds. Every event gets its own art-directed poster from centralized design metadata. Keep a visible directory and fullscreen native details, all canonical fields, image fallbacks and focus/position restoration. A short stage-origin festival-banner transition integrates without homepage source edits. Midnight/coral/orange/lime/cream extend existing master branding. No fake photography, real-campus geography, component templates, audio or WebGL. Other pages, intro, VJIT, sponsors, registration and route controller remain protected. Hosted 21st search is not signed in; local guidance/review are available.

## Technical design context

The current Technical-only brief selects **The Invention Engine — Build What’s Next**. Warm off-white, graphite, electric blue and selective orange frame a single persistent mechanical assembly. Four immediately available independent event modes transform the same modules, core, connections, gantry and display envelope. Architectural navigation and a reactive editorial event panel replace directory/cards. Native fullscreen details use their own short precision motion and canonical fields. A pavilion-origin blueprint aligns the same assembly into the destination page. Mobile simplifies drafting annotations and uses a deliberate compact selector/canvas composition. No terminal, crypto/SaaS dashboard, glowing circuits, fake projects/branches/photos, autoplay audio or heavy dependencies. Homepage/VJIT, intro, Sports, Cultural Street, sponsors, registration and existing route lifecycle remain protected.
