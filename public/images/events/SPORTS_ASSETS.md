# Sports photography mapping

Add approved photos under basketball/, football/, volleyball/, table-tennis/, cricket/, badminton/, chess/, carroms/ or kabaddi/. Set the matching images array in src/data/sportsAssets.js using `{ src: '/images/events/basketball/01.webp', alt: 'Accurate description of the approved image' }`.

Image 0 is the main journey/detail photograph. Additional images appear in the detail image controls. Empty or broken sources use the sport's original SVG placeholder. No actual sports photographs are installed. Posters are reserved in the same mapping for future presentation and are not currently rendered.
